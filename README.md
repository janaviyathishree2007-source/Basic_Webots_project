# 🤖 Webots Robot Simulation Project

## 📌 Overview

This project was developed using **Webots**, a robotics simulation platform used to design, simulate, and test robotic systems in a virtual environment.

The project focuses on simulating a robot and implementing its movement and behaviour using a programmed controller. It provided hands-on experience with robotics, simulation, sensors, and robot control.

## 🎯 Objectives

* To understand the basics of robotic simulation using Webots.
* To create and configure a robot in a virtual environment.
* To program the robot's movement and behaviour.
* To understand how sensors can be used for robot navigation and interaction.
* To test and observe robotic behaviour in a simulated environment.

## 🛠️ Technologies Used

* **Webots** – Robot simulation
* **Python** – Robot controller programming
* **Robotics** – Robot movement and control
* **Git & GitHub** – Version control and project sharing

## ⚙️ Project Features

* Virtual robot simulation
* Programmed robot movement
* Sensor-based interaction
* Real-time simulation and testing
* Controller-based robot behaviour

## 📂 Project Structure

```text
Webots-Project/
│
├── worlds/

│
├── controllers/

│       └── robot_controller.py
│

```

### Folder Description

| Folder         | Description                                 |
| -------------- | ------------------------------------------- |
| `worlds/`      | Contains the Webots simulation world files  |
| `controllers/` | Contains the programs controlling the robot |
| `protos/`      | Contains custom Webots objects, if used     |
| `README.md`    | Project documentation                       |

## ▶️ How to Run the Project

### 1. Install Webots

Download and install Webots on your computer.

### 2. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 3. Open the Project

Open Webots and load the `.wbt` file located inside the `worlds` folder.

### 4. Run the Simulation

Run the simulation and observe the robot's behaviour.
